How it works

QR codes are everywhere in small operations: labels on shelves and boxes, asset tags on laptops and tools, tickets and badges for events, links on product packaging and menus. The data behind them usually already lives in a spreadsheet: a list of products, locations, serial numbers or guests.

Making one QR code is easy. Making five hundred, each with a different link or ID, is tedious. People copy rows into an online generator one by one, download the images, rename the files and try to match them back to the right row before printing.

The add-on works where the data already is. You open your Google Sheet, choose the column that holds the links, IDs or text, and pick where the codes should go. One run creates a QR code for every row and places it in the sheet as a high-resolution image.

Each code stays in the same row as its data, so it is always clear which code belongs to which product, location or person. Rows can be sorted and filtered, and the codes move with them.

When the data changes, you run it again and only the rows that changed get a new code. New rows added at the bottom of the list get their codes in the same run.

For printing, a label layout puts each code together with a caption taken from any column, such as the product name, the location or the guest's name. You choose the size of the codes and how many fit on a page, and print the sheet or save it as a file for a print shop.

Codes can be set to a size and error correction level that suits the job: small codes for packaging, larger ones for signs and shelves that are scanned from a distance.

The add-on is for anyone who keeps lists in Google Sheets and needs codes for them: warehouses and shops, schools and offices tagging equipment, event organisers, makers who label products. Nothing needs to be installed on a computer; it runs inside Google Sheets.

A code can hold a web link, a product or asset ID, a short text, contact details or a link with tracking tags for a campaign. Different rows can hold different kinds of data, and a separate column can set the caption printed under each code, so one sheet can serve shelves, boxes and signs at the same time.
